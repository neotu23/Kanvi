# Kanvi

本地运行的公众号风格提取与文章排版工具。

提供一篇喜欢的公众号文章作为设计参考，经 AI 分析、样例排版、规则检测和公众号实际预览后，保存为自己的模板。以后导入 Obsidian Markdown 文档，选择或推荐一个已验证模板，生成可预览、导出和复制到公众号的正文。

## 当前状态

2026-09-14：完成项目文档初始化，设计基线整理于 2026-09-13。应用尚未开发，没有安装运行依赖，也没有进行公众号实测。

当前目录采用 Git 管理；本次范围仅为本地仓库和执行文档。不创建远程仓库，不部署网站。

## 设计原则

- 纯文字优先，不提供完整富文本编辑器。
- 风格来自用户的参考文章，不限于开源编辑器的预设 Markdown 主题。
- 默认保留原文和顺序；AI 负责风格分析、模板选择与局部修正建议。
- 模板、文章、检测报告和历史记录保存在本机；DeepSeek API 请求会把所选内容发送给模型服务。
- 程序检查通过与公众号实际预览通过分别记录。
- 预览、检测、导出和富文本复制必须使用同一份最终正文 HTML。
