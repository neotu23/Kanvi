## 阶段 1：验证输出、检查和复制链路

**目的：** 不接 AI、不抓文章，先用自写 HTML/CSS 验证核心路径。

**交付：** 固定上游版本；合法样例及故障样例；处理适配器；官方检查适配器；简单预览/复制页；事实化验证报告。

**验收：** 内联处理保留原文和自定义布局；检测器识别预期问题，进程故障不判通过；浏览器能复制富文本；用户实际粘贴验证记录与程序检查分开。

**决策：** WeMD 可独立使用则复用必要核心；不适合时采用 Juice 加具名适配规则。检查器运行失败时报告具体障碍，不用第三方主题替代官方检测。

## 阶段 2：参考读取与设计分析

**计划文件：** `src/features/references/{fetch-reference,extract-article,reference-schema}.ts`、`src/features/ai/{client,design-analysis}.ts`、`src/app/api/references/route.ts`。

- [ ] 以自写 HTML 建立正文提取样例，覆盖无正文、验证码、重定向、超时和大小限制。
- [ ] 完成来源读取、正文区域提取和来源快照；对外部 URL 逐次校验。
- [ ] 定义设计分析 schema：文本样式、区域结构、标签、证据位置、估计项和不支持元素。
- [ ] 用固定模型响应验证 schema，拒绝额外脚本、无证据结构和无效颜色/尺寸。
- [ ] 接入本地服务端 DeepSeek 请求；仅用户选择内容可发送，密钥不进入客户端。
- [ ] 用一个用户提供的参考链接验证读取与分析；无链接时使用自写样例，不伪造真实提取成功。

**验收：** 分析结果可以回溯至来源；失败清晰可见；模型未配置时仍可查看已读取参考。截图通道仅在所选模型支持图像时启用。

## 阶段 3：模板、样例、检查和修正

**计划文件：** `src/features/templates/{schema,render,repository,status}.ts`、`src/features/validation/{repair,verification-record}.ts`、`src/app/templates/`。

- [ ] 定义声明式模板结构及版本数据，包含可重复、可省略和支持的内容类型。
- [ ] 渲染时转义文字，禁止模板执行 JavaScript；测试长标题、空引用和多段重复。
- [ ] 实现本地原子写入与不可变版本，新版本不继承旧版本的实际验证状态。
- [ ] 生成覆盖模板元素的样例，调用阶段 1 的检查器。
- [ ] 程序修正只处理明确规则；AI 返回受限补丁，最多两轮；修正前后比较文字完整性。
- [ ] 增加实际公众号验证登记，记录版本、样例哈希、设备、日期及结论。
- [ ] 完成第一套真实已验证模板，保留修正历史和最终样例。

**验收：** 检测通过仅进入待公众号验证；只有对应样例被用户实际确认后进入已验证。失败及未验证状态不能伪装成可直接复用的已验证模板。

## 阶段 4：Markdown 原文保真套版

**计划文件：** `src/features/articles/{parse-markdown,obsidian,content-integrity,render-article,repository}.ts`、`src/app/generate/`。

- [ ] 将 Markdown 转为带 ID 和源位置的内容块，覆盖标题、段落、引用、列表、强调、分隔线。
- [ ] 明确属性区、双链、提示块的转换；未支持的嵌入/脚注列出诊断，不删除后继续显示成功。
- [ ] 检查模板结构适配性，再从原文读取内容填充模板。
- [ ] 对两篇长短和结构不同的自写日记验证无新增、无遗漏、无重复、顺序正确。
- [ ] 运行本篇布局检测并展示结果；保存同一份最终正文用于预览、导出和复制。

**验收：** 手动选择已验证模板可完整生成文章，不依赖 AI；模板不支持的结构有明确处理入口。

## 阶段 5：AI 模板推荐

**计划文件：** `src/features/templates/{eligibility,recommend}.ts`、`src/features/ai/template-recommendation.ts`。

- [ ] 准备至少三套已验证的纯文字模板及区别明显的设计标签。
- [ ] 用结构硬条件筛选候选，再发送文章必要信息和候选设计描述。
- [ ] 校验推荐只能引用候选中的模板 ID 和版本，返回主推荐、备选及原因。
- [ ] 覆盖无候选、模型超时、无效 JSON、未知 ID、重复备选等失败情况。
- [ ] 保留用户手动选择路径；没有 AI 不影响已有模板渲染。

**验收：** 不会推荐未验证或结构不适配模板；不为模仿风格而改写日记。

**验收：** 一个新用户能按 README 本地启动并完成主流程。无自动发布、云账号系统和完整富文本编辑器。

## 失败处理与验收证据

| 失败 | 产品行为 | 保存证据 |
|---|---|---|
| 公众号读取失败 | 保留链接和错误，提供 HTML/截图备用入口 | 错误类型、时间、阶段 |
| 模型响应无效 | 拒绝无效结果，可重试或手选模板 | 脱敏错误，不保存 Key |
| 内联失败 | 阻止标为适配完成 | 模板版本、输入哈希、错误 |
| 检查器故障 | 显示检测失败，不等同于零违规 | 退出码、脱敏日志、版本 |
| 两轮后仍有问题 | 保留待调整状态 | 前后差异及剩余规则 |
| 实际粘贴变化 | 修改模板新版本并重测 | 截图、设备和样例哈希 |
| 不支持的 Markdown | 定位原文，要求明确处理 | 内容类型、源位置 |
