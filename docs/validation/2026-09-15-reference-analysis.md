# 第二阶段：参考导入与设计分析验证报告

日期：2026-09-15。范围：本机代码、自动功能测试和生产服务接口。没有执行公众号实测、系统粘贴或浏览器交互模拟。

## 已交付

- `/references` 页面：链接或 HTML 文件导入、本地参考列表与分页、证据查看、设计分析与独立历史。
- 参考提取：唯一正文定位、原始来源保留、元素证据 ID、匹配正文的静态样式声明、媒体与不支持样式诊断。
- 受限抓取：HTTPS 精确微信文章主机，拒绝账号密码/非标准端口，固定经校验的公网 DNS 地址，每跳重新校验，最多三次跳转。整次 15 秒超时，传输和解压后的内容均最多 2 MiB。
- 本地保存：发布前验证，临时目录内完成写入再原子重命名，已发布版本不可覆盖。重复参考按原始来源指纹合并；每次分析保存独立 ID。
- DeepSeek：固定官方 API 端点，服务端 Key、结构化 JSON、输入/响应限额、超时和取消、错误脱敏、字段与证据校验。未配置时导入仍可用。
- 设计草稿包含标签、文字样式、区域、来源 ID、估计项与不支持项。颜色和尺寸为受限数据，不接受脚本、JSX、任意属性或表达式。

## 边界和采用决策

- 真实公众号链接读取和真实 DeepSeek 调用未执行。没有用户提供的测试链接或用于本阶段验证的服务端 Key，不能据受控测试声称外部服务已经跑通。
- 静态证据记录声明，不计算实际层叠、继承或布局。只与正文匹配的样式参与提取；不相关的未匹配页面样式不作为遗漏的文章风格。
- 原始 HTML 上限 2 MiB；JSON 包络考虑 `\uXXXX` 转义膨胀，上限约 12 MiB，按实际流字节计数；解码后仍执行 2 MiB HTML 限制。
- CSS 上限 128 KiB、正文最多 1000 元素、最多 1500 条样式规则与 12000 条匹配声明；超过限制明确失败。
- AI 输入最多 100 KiB、响应最多 512 KiB、总超时 60 秒。模型不自动重试，用户可手动发起下一次分析。
- schema 校验能证明字段合法及证据 ID 存在，不能证明模型对证据的语义解读正确。草稿不等于可用模板，更不等于公众号实测通过。
- 不新增生产依赖；沿用锁定的 Cheerio/PostCSS 和 Node 自带网络、流与文件系统功能。上游检查器依赖状况沿用第一阶段报告，原始参考不送入该检查器。
- 初次工作区构建因依赖符号链接越过 Turbopack 根目录失败；改为工作区内依赖副本后标准生产构建通过。没有改变项目构建配置来隐藏错误。

## 官方接口依据

2026-09-15 核查 [DeepSeek 模型表](https://api-docs.deepseek.com/quick_start/pricing/)、[Chat Completions](https://api-docs.deepseek.com/api/create-chat-completion/) 和 [JSON 输出说明](https://api-docs.deepseek.com/guides/json_mode/)。当前采用 `deepseek-flash`，端点 `/chat/completions`，非流式 JSON 输出；默认禁用思考模式。模型名称可在服务端配置，不假定别名永远指向同一模型版本。

抓取实现参考 [Node HTTPS](https://nodejs.org/download/release/latest-v24.x/docs/api/https.html)、[DNS](https://nodejs.org/download/release/latest-v24.x/docs/api/dns.html)、[Net](https://nodejs.org/download/release/latest-v24.x/docs/api/net.html) 与 [Zlib](https://nodejs.org/download/release/latest-v24.x/docs/api/zlib.html)。`lookup` 返回固定的校验地址，保留 TLS 主机名验证；全程共享取消信号，解压后再次计数。
