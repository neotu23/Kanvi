# 主题文章预览与正文入口

日期：2026-09-25。

## 改动

- `/styles` 默认打开第一套可用主题。选主题时，以该主题 `THEME.md` 的 root、hero、h2、paragraph、blockquote、footer 槽位装配同一篇完整文章，保留槽位原有样式。
- 自写示例《把一个下午还给自己》保存在 `public/samples/slow-afternoon.md`；界面支持下载。预览不调用 DeepSeek，上游主题包文件不修改。
- 预览使用独立 iframe，根据正文高度、字体加载与宽度变化重新测量，取消固定高度与内部滚动条。
- “生成正文”先显示为入口。已保存主题预览成功后即可点击顶部入口打开 Markdown 输入区，无需额外确认；仅未保存的生成草案显示“未保存主题”按钮，点击可保存入库。底部两个按钮移除。切换主题保留输入。旧请求回包不会覆盖新主题，重新选择同一主题可以重试。
- 草案预览不能直接进入正文生成，仍须先确认入库。实际文章生成仍沿用已有保存历史、原文保真与规格检查链路。
- 预览只允许有限标签和内联样式，禁止脚本、事件和导航，CSP 禁止外部资源，iframe 不授予脚本权限。缺槽、未知变量、无法保留完整正文时明确失败，不退回占位文案。
