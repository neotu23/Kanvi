## 2026-10-13 原文目录修复

正文生成默认只排版原文，原文没有目录时不再提炼“三看点”，已有目录保留原标题、条目数量、顺序与位置。最终提示词覆盖主题和上游的目录要求；模型仍新增、重复或扩写可识别目录时判为“需修正”并展示原因，不开放通过后的富文本复制。旧历史继续按原提示词版本复算，需重新“生成并检查”使用新规则。217 项自动测试、类型检查、生产构建与上游版本检查通过；未执行真实模型调用、浏览器交互模拟或公众号实测。详见[原文目录修复验证](validation/2026-10-13-source-toc.md)。

## 2026-10-12 正文可选字段修复

缺少日期、作者和简介时，不再保留主题生成的独立占位行；属性区已提供日期时使用该值，已有署名保留，不编造日期或作者。处理只适用于独立的主题可选空行，并在处理前检查原始产物，未知占位符、原文字面符号和其他违规仍由原有门禁拦截。旧历史不修改，需重新点击“生成并检查”，全部通过后使用“复制到公众号”；“复制全文”仍是 HTML 源码。194 项自动测试、类型检查和生产构建通过，详见[可选字段修复验证](validation/2026-10-12-optional-metadata.md)。

## 2026-10-11 DeepSeek 配置更新

`/settings` 新增“DeepSeek 模型”区块，可填写与保存 API Key、模型名，测试连接（一次 `/models` 请求），以及清除本地密钥。保存写入 `data/settings.json`（0600，已在 `.gitignore` 内），无需重启即生效；生效顺序为本地设置优先、环境变量回退，设置文件损坏时明确报错并保留原文件、不静默覆盖。密钥只回显尾 4 位，接口拒绝非本机请求与越权字段，备份导出同时检查环境变量与本地设置中的密钥。188 项自动测试、完整类型检查及生产构建通过；连接测试的失败分支由受控 transport 覆盖，未对真实 DeepSeek 验证 Key 可用性，浏览器交互模拟与公众号实测未执行。

## 2026-09-26 主题切换体验更新

首页与模板制作页换主题时不再清空正文预览，旧正文保留到新正文就绪，滚动位置不再被浏览器挤回页首。正文切换优先交给浏览器原生视图过渡做交叉淡化：新旧画面抓取之间会等新正文渲染完成并量好高度，`view-transition-name` 只作用于正文区，页面其余部分不参与；浏览器不支持或用户选择减少动效时，退回组件自己的淡出淡入。182 项自动测试、完整类型检查及生产构建通过；视图过渡与 iframe 截图属浏览器行为，本次未执行浏览器交互模拟，效果需在 Chrome 实测确认。
